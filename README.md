# Image Gallery

## Project Description
This project is a responsive Image Gallery developed using HTML, CSS, and JavaScript. It displays nature images in a grid layout and provides interactive features such as Lightbox View, Next/Previous navigation, Hover Effects, Smooth Transitions, and Category Filters.

## Features
- Responsive Image Gallery
- Lightbox View for enlarged image display
- Next and Previous navigation buttons
- Hover Zoom Effects
- Smooth CSS Transitions
- Category Filter (All, Nature)
- Mobile-Friendly Responsive Design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or save all project files in the same folder.
2. Open `index.html` in any web browser.
3. Click on an image to open it in Lightbox mode.
4. Use Next (❯) and Previous (❮) buttons to navigate.
5. Use filter buttons to display images by category.
6. Hover over images to see zoom effects.

## Functionality

### HTML
- Creates the gallery layout.
- Adds images and filter buttons.
- Contains the Lightbox structure.

### CSS
- Styles the gallery.
- Adds hover effects and transitions.
- Makes the design responsive.

### JavaScript
- Opens selected image in Lightbox.
- Navigates images using Next/Previous buttons.
- Closes Lightbox.
- Filters images by category.

## Output
The gallery displays nature images in a responsive grid layout. Users can:
- View images in full-screen mode.
- Navigate between images.
- Apply category filters.
- Experience smooth animations and hover effects.
